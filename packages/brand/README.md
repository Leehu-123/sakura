# Bộ nhận diện Sakura dùng chung

Logo gốc do chủ dự án cung cấp từ Desktop/Sakura ngày 08/09/2026. Giữ nguyên file ảnh, màu sắc và chữ; không vẽ lại, kéo méo hoặc cắt mất slogan. Sử dụng trên nền trắng.

Các frontend thêm dependency @sakura/brand và import @sakura/brand/logo.jpg. Sale Web dùng trên màn hình đăng nhập, thanh bên, màn hình tải và biểu tượng tab. App Kho/Nhân sự sau này dùng cùng nguồn.

Ảnh JPEG hiện có lề trắng và slogan. Khi cần biểu tượng nhỏ sắc nét hơn, dùng bản vector/transparent chính thức nếu thương hiệu cung cấp.
